# Fonts

Both families are used under the SIL Open Font License 1.1, which permits
self-hosting and redistribution.

- **Spectral** — Production Type. https://fonts.google.com/specimen/Spectral
- **IBM Plex Sans** — IBM. https://fonts.google.com/specimen/IBM+Plex+Sans

Only the `latin` subset is vendored, and only the five faces the design system
actually uses. See src/styles/fonts.css for why five.
